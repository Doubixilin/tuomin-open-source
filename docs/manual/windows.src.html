本机脱敏、文件处理与 AI 工具接入

Windows x64 便携版 · 2026-10-27 · 含离线识别模型
启动与更新剪贴板选中文字文件词典工具接入数据与退出

本手册的业务页截图沿用同版本 Mac 界面的合成演示，帮助定位功能；Windows 窗口边框、托盘、快捷键与权限以本页文字为准。检测结果需要人工核对，不承诺零遗漏。

1 · 启动与更新

  1. 从托盘菜单退出正在运行的旧版。
  2. 把 ZIP 完整解压到固定文件夹；保留 _internal 和所有随包文件，不能只复制 EXE。
  3. 双击 Tuomin.exe 打开工作台。Tuomin-cli.exe 供 MCP、命令行与排错使用。
  4. 首次向导中选择词典来源，默认「本机工作台」。按需开启登录启动，并配置快捷键。

桌面窗口使用系统 Microsoft Edge WebView2 Runtime。若缺少该组件，请通过微软官方安装程序补齐。此便携包未做 Authenticode 签名。

后续移动安装文件夹时，在「工具接入」重新写入客户端配置。原有数据默认存放在 %APPDATA%\Tuomin。

2 · 复制 → 脱敏 → 回填

  1. 复制一段文字，按 Ctrl+Alt+D，或在托盘选择「脱敏剪贴板」。
  2. 确认结果后粘贴到 AI 对话框。对方收到占位符，原值留在本机。
  3. 复制 AI 回答，按 Ctrl+Alt+R，或选择「回填剪贴板」，再粘贴回文档。

在设置中点击快捷键输入框并按组合键即可录制，清除后不再绑定该动作。支持 Ctrl、Alt、Shift、Win，F13–F24 可单独使用。注册冲突会显示提示。

同一剪贴板会话保持占位符一致；托盘可查看最近结果、查看对照表、新建或清除会话。

3 · 选中文字与就地替换

三项动作默认不绑定快捷键，需要在设置中自行启用：

动作结果
脱敏选中文字模拟复制所选文本，把脱敏结果放入剪贴板；原文不变。
选中脱敏并替换把所选文字替换成脱敏版，再恢复之前的剪贴板文本。
选中回填并替换把所选占位符回答还原后粘贴，再恢复之前的剪贴板文本。

请在支持 Ctrl+C / Ctrl+V 的应用中使用，处理完成前不要切换窗口。目标窗口或修饰键状态变化会取消替换。Windows 不需要 Mac 辅助功能授权；权限较高的目标程序可能拒绝模拟按键，此时手动复制后用普通剪贴板动作。

剪贴板恢复仅保留文字，不保留图片、文件列表或富文本格式；使用前请先保存需要保留的剪贴板内容。

4 · 文件脱敏、终止与回填

打开「文件脱敏」，选择文件和词典来源，处理后保存结果。长任务可以点击「终止」；服务会协作取消处理。

Windows 托盘提供「选择文件脱敏…」，可一次选择多个文件，输出到原文件旁，重名时自动编号。完成后从托盘的结果菜单打开所在文件夹。Finder 服务和 Dock 拖放属于 Mac 入口。

Word、Excel、PPT 使用原格式处理；PDF 与文本快捷处理输出 Markdown。旧版 .doc / .xls 需要本机安装 LibreOffice。加密、宏、签名或不支持的嵌入对象可能被阻断，页面会说明原因。

「文件回填」可选择对应任务恢复，恢复包用于另存备份。AI 回答回填时也要选择原任务或对应智能体会话，不能混用占位符。

5 · 维护本地词典

在「本地词典」批量粘贴或导入 CSV / Excel，先预览识别列与重复项，再提交。可导出、复制到其他应用，或从脱敏结果中学习词条。

词典用于补充本单位、项目和客户名称。切换来源后核对当前应用，避免把无关词条引入其他任务。

6 · AI 工具接入与 WorkBuddy

在「工具接入」选择客户端，点击「写入」可配置 MCP，并按需安装随包技能。支持 Claude Code、Codex、Cursor、Claude Desktop 和 WorkBuddy。写入保留备份，移除仅处理 Tuomin 项。

MCP 默认指向 Tuomin-cli.exe --mcp-stdio。点击「自检」检查命令启动、协议、就绪状态与合成文本脱敏；真实客户端加载仍需在客户端中确认。

WorkBuddy 自定义模型接入需要选择已配置上游模型的应用。生成后会备份并修正旧类型字段；「校验」检查本地格式与当前网关地址，不能代替真实模型对话验证。

智能体可调用脱敏和会话接口，原值回填由本机工作台完成。测试功能使用合成文本。

7 · 数据、退出与卸载

默认数据目录为 %APPDATA%\Tuomin，自定义启动可使用独立数据目录。映射采用 Windows DPAPI 加密；应用凭证、配置和词典使用受保护文件权限。复制数据到另一个 Windows 用户或另一台机器不保证能解密原映射。

关窗口只隐藏到托盘；选择「退出 Tuomin」才结束服务。最近有外部工具调用时会提示确认。退出会中断仍在运行的任务，请先保存结果。

  1. 卸载前在「工具接入」移除客户端中的 Tuomin 配置，并关闭「登录时启动」。
  2. 从托盘退出，然后删除解压的程序文件夹。
  3. 只有确定不再需要回填时，才清除数据目录；删除映射会失去对应任务的恢复能力。

本包自动检查不替代真实桌面操作、第二台机器或安全软件环境的人工复测。
