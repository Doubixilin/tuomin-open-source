Tuomin 本地脱敏工作台 · 使用手册

把文字和文件里的单位名、人名、电话、账号、合同号等敏感信息，在你自己的电脑上换成 <ORG_001> 这样的占位符，再交给 AI；拿回 AI 的回答后，同样在本机换回原文。

适用版本：0.1.0（构建 20261024.5）· macOS 26.5 及以上，Apple 芯片 · 文中截图均来自真实界面，示例数据为虚构

1认识 Tuomin

Tuomin 是一个只在本机运行的"脱敏 + 回填"工具。它不替你回答问题，而是让你可以放心地把材料交给任何 AI。

本机原文甲方 示例建设集团，联系人 张三
本机脱敏识别敏感信息，换成占位符，对照表留在本机
云端 AI提问甲方 <ORG_001>，联系人 <PERSON_001>
云端 AI回答建议 <ORG_001> 在签署前补充验收标准
本机回填建议 示例建设集团 在签署前补充验收标准
只在本机服务只监听 127.0.0.1，原值、对照表和词典都不离开这台电脑。
识别靠三层规则（电话、证件、账号等）+ 你的词典 + 本地中文实体识别模型（Full 版内置）。
结果可还原同一会话里同一原值始终对应同一个占位符，AI 的回答能准确换回原文，还原你当时的写法。
请注意Tuomin 是数据最小化工具，不承诺零漏检。图片中的文字、扫描件 PDF 不会被识别；重要材料发出前，请在「核对与原值」里看一眼占位符覆盖是否完整。

2安装与首次启动

  1. 双击 Tuomin-0.1.0-macos-arm64-…dmg，把 Tuomin 拖到「应用程序」文件夹。不要直接在 DMG 里运行：那样 AI 工具接入写入的路径会在推出磁盘后失效。
  2. 从「应用程序」打开 Tuomin。如果提示"无法验证开发者"，到「系统设置 → 隐私与安全性」，在下方点「仍要打开」，只需一次。
  3. 首次启动会弹出欢迎向导：选择剪贴板使用的词典（默认「本机工作台」），按需勾选「登录时启动」，点「完成」。向导里也能直接跳到快捷键、AI 工具接入和词典导入。
  4. 菜单栏右上角出现 Tuomin 图标，说明服务已在后台运行。关闭窗口不会退出；要退出请点菜单栏图标 →「退出 Tuomin」，或在 Dock 图标上右键选「退出」，也可以按 ⌘Q。
不需要激活本版本打开即可使用，没有授权码，也不联网下载任何东西。Full 版内置中文实体识别模型；Lite 版不含模型，只用规则和词典。

4剪贴板：最快的用法

不用打开窗口。在任何应用里复制，按快捷键，粘贴给 AI；拿到回答再按一次，还原后粘回文档。

  1. 在微信、邮件、Word 等任何地方复制一段文字，按 ⌥⌘D（或点菜单栏「脱敏剪贴板」）。剪贴板里的内容被替换成脱敏版，并提示"已脱敏 N 处"。
  2. 粘贴到任意 AI 对话框提问。
  3. 复制 AI 的回答，按 ⌥⌘R（或点「回填剪贴板」），再粘贴到你的文档。还原的是你当时的写法：写的是简称就还原成简称。

会话：让占位符保持一致

  • 同一个剪贴板会话里，多次复制的同一个名称始终是同一个占位符，所以可以分几段发给 AI。
  • 空闲 8 小时（可在设置里改）后自动开始新会话。菜单「剪贴板会话」里可以新建会话、结束并清除，或在工作台查看对照表。
  • 回答要在产生它的那个会话里回填。新会话里回填旧回答，可能和同名占位符混淆。
不会覆盖剪贴板的情况检测器未就绪、含禁止外发的内容、回答里有未知或被改写的占位符、处理期间剪贴板被其他应用改了。此时剪贴板保持原样，菜单栏和通知会说明原因。

选中即脱敏（不用先复制）

在「设置」里给下面三个动作绑定快捷键，就可以直接对选中的文字操作：

动作效果适合
脱敏选中文字脱敏结果放进剪贴板，原文不动选中一段话，马上粘贴给 AI
选中脱敏并替换选中的内容直接变成脱敏版，你原来的剪贴板会被恢复在文档里就地处理一段内容
选中回填并替换选中的 AI 回答直接变成原文，原文不会留在剪贴板把粘进文档的 AI 回答就地还原

这三项需要 macOS 的「辅助功能」权限（用来模拟一次 ⌘C / ⌘V）：

  1. 第一次按快捷键时，系统会弹出授权提示；或在「设置」里点「请求授权」。
  2. 在「系统设置 → 隐私与安全性 → 辅助功能」里打开 Tuomin 的开关。
  3. 回到原来的应用，选中文字，再按一次快捷键。
不授权也没关系其他快捷键和菜单动作照常可用。Tuomin 只在你按下快捷键的那一刻读取一次剪贴板，从不在后台监听。

5文本脱敏

粘贴一段文字，立刻看到哪些内容被识别、换成了什么。适合核对规则和词典的效果。

  • 示例：一键填入合同、投资、个人信息、诉讼等示例文本。
  • 档位：决定哪些类别被替换（见第 11 章）。勾选「全部档位」可看到所有场景、档位与敏感级。
  • 统计：识别项、替换为占位符、不可逆泛化（例如金额换成区间，无法还原）、禁止外发的数量。
这里只预览文本脱敏不保存对照表，也不能回填。要回填，请用剪贴板或文件脱敏。

6文件脱敏

原文件不会被修改。Word、Excel、PPT 可以导出保留原排版的脱敏文件；其他格式输出脱敏后的文本。

  1. 点「选择文件」，在「使用词典」里选应用（默认「本机工作台」）。不选词典时只能本地预览，结果禁止外发。
  2. 二选一：
    • 解析并脱敏：输出脱敏后的文本（Markdown），适合把内容粘给 AI。
    • 导出原格式脱敏文件：生成同样排版的 .docx / .xlsx / .pptx，适合直接上传给 AI 或发给同事。
  3. 看出站闸门：绿色"通过"才表示可以交给在线 AI；红色会列出原因（例如含身份证号这类禁止外发的内容）。
  4. 点「保存脱敏文件…」或「保存脱敏文本…」选择保存位置。点「把识别出的名称加入词典…」可以让下次识别更稳（见 9.3）。

支持的格式

格式原格式导出说明

Tuomin 正在运行时，命令行直接使用它；没运行时在命令行进程内处理。

7回填还原

对照表保存在本机，回填时只要选对"任务"，不需要口令或恢复包。文件任务可在一年内回填；剪贴板会话和智能体会话请在 24 小时内回填。

文件回填

AI 把脱敏文件改写后发回来，在「文件回填」里选择改写后的文件和对应任务，点回填。原格式文件（docx/xlsx/pptx）回填后仍保留排版。

回答回填

  1. 把 AI 的回答粘进文本框（或导入 .md / .txt）。
  2. 在「对应任务」里选脱敏时的那次任务。
  3. 点「本地回填」，下方显示还原后的回答和每个占位符的使用次数。

智能体会话

Claude Code、Codex 等 AI 工具通过 Tuomin 脱敏时（见第 10 章），每次对话是一个「智能体会话」。在「对应任务」下拉的「智能体会话」分组里，按时间选中对应的那一项即可还原 AI 的回答。

回填被阻断时"未知占位符"通常是选错了任务；"占位符被改写"是 AI 改动了编号或括号（例如写成 <ORG 001>），修正后再回填。回答里一个占位符都没有时，会请你确认后再按原文返回。
换电脑或长期归档在「文件脱敏」页可以导出加密的恢复包（.tuominmap），回填页展开「改用恢复包文件」即可使用。日常在本机回填不需要它。

8核对与原值

发出去之前最后检查一遍：原文、脱敏结果、AI 回答、回填结果并排对照；需要时显示占位符对应的原值。

敏感区域对照表显示的是真实原值。离开页面、切换窗口或 90 秒无操作会自动锁定，内容不写入任何缓存或日志。请勿截图或转发。

9本地词典

规则能识别电话、证件、账号这类有固定格式的信息；单位、客户、项目的名称和简称，最可靠的办法是放进词典。

9.1 添加与管理词条

在「词典所属应用」里选应用（默认「本机工作台」，剪贴板和文件脱敏都用它），填写名称、类型、别名和风险等级后点「添加」。同一实体的简称写在别名里，回填时按你当时的写法还原。

9.2 批量导入

  1. 「来源」选粘贴文本、选择文件（CSV / Excel .xlsx / 导出的 JSON）或「从其他应用复制」。
  2. 粘贴时每行一个：名称,类型,别名|别名,风险，后三项可以省略；只写名称时，在「缺省类型」里选类型。
  3. 点「预览」，逐行查看结果；确认没问题后点「确认导入」，只有没问题的行会写入。
类型写法含义
ORG 或 单位 / 公司 / 机构单位名称
PERSON 或 人名 / 姓名 / 联系人人名
PROJECT 或 项目 / 工程项目名称
SUPPLIER 或 供应商；CUSTOMER 或 客户供应商、客户
ADDRESS 或 地址地址
其他大写英文，如 CONTRACT_ID自定义类别

Excel / CSV 第一行可以写表头「名称、类型、别名、风险」（顺序不限），没有表头时按这个顺序读取。风险等级可写 low / medium / high / critical 或 低 / 中 / 高 / 极高，默认 high。

9.3 从脱敏结果学习

选一次文件脱敏或智能体会话，点「查找新名称」，列出本次识别出、词典里还没有的单位、人名、地址等。勾选、调整类型后点「加入词典」。文件脱敏完成后，点「把识别出的名称加入词典…」会直接跳到这里。

10让 AI 工具直接调用

在 Claude Code、Codex、Cursor、Claude Desktop、WorkBuddy 的对话里，让 AI 先调用 Tuomin 脱敏，再处理材料。

  1. 打开「工具接入」，找到你用的客户端，点「写入」。支持 skill 的客户端会同时安装 tuomin-guard skill（教 AI 正确使用脱敏、不碰占位符）。
  2. 点「自检」，四步全部打勾即说明配置可用。
  3. 按卡片上的提示重启客户端。之后在对话里说"先用 tuomin 脱敏这段材料再分析"即可。
  4. AI 的回答里有占位符时，到「回答回填」选择对应的「智能体会话」还原（见 7 章）。
客户端写入位置Skill生效方式
Claude Code用户级 MCP（优先用 claude mcp add）自动安装新开会话，/mcp 可查看
Codex~/.codex/config.toml自动安装重启 Codex
Cursor~/.cursor/mcp.json无用户级 skill在 MCP 设置里确认启用
Claude Desktopclaude_desktop_config.json点「下载 skill」后在 App 内上传完全退出后重开
WorkBuddy~/.workbuddy/mcp.json自动安装在「连接器」里确认启用
安全设计写入的配置里只有 Tuomin 的启动路径，没有任何密码或令牌。AI 只能脱敏，不能回填，也看不到原值；同一次对话里多次脱敏使用同一套占位符。写入前会自动备份原配置，「移除」只删除 Tuomin 自己写入的那一项。
  • 智能体使用的词典：默认与「本机工作台」相同，可在卡片顶部切换后点「应用」。
  • Tuomin 没开时：AI 第一次调用会在后台自动启动已安装的 Tuomin。
  • 其他客户端：展开「MCP 启动命令」，复制命令配置到任何支持 STDIO MCP 的工具。
  • 更换凭证：随时可以更换智能体凭证，已接入的客户端无需改动。

聊天端点与 WorkBuddy 自定义模型

另一种接法是把 Tuomin 当成"模型地址"：客户端照常发请求，Tuomin 在中间脱敏、转发给真正的模型，再把回答还原。每个应用有三个端点：

端点效果适合
masked回答全程保留占位符，需要到 Tuomin 回填自检、检查覆盖情况
demo思维链保留占位符，正文自动还原演示"脱敏确实发生了"
auto全程自动还原，使用体验与直连模型相同日常使用

WorkBuddy 可以用向导一步完成：在下方「一键创建」新建项目应用（填上游模型地址与模型，默认 DeepSeek），选中它，填写上游 API key，点「生成并写入 WorkBuddy」，再点「校验」。WorkBuddy 会自动重载，模型下拉里选「<应用>·脱敏·无感回填」即可。

只有配置了上游模型的应用才能接入首次启动自带的「本机工作台」「剪贴板」是给文件和剪贴板用的，没有上游模型，下拉里会显示为不可接入。API key 只写进 WorkBuddy 自己的配置，不进 Tuomin、不进日志。

11应用与档位

每个接入的工具对应一个"应用"，决定用哪本词典、脱敏有多严格。桌面使用一般用默认的「本机工作台」即可。

档位效果
通用（推荐）识别到的全部替换，可以完整回填。文件与剪贴板默认使用。
合同审查保留合同分析需要的结构，交易各方按角色（甲方、乙方、担保人）占位。
投资项目适合投资尽调材料。
诉讼文书法院、案号等公开信息按需保留，当事人信息替换。
严格更多类别一律替换，适合最敏感的材料。

部分档位会把金额换成区间、把地址概括到省市（"不可逆泛化"），这些内容回填时无法还原；需要完整回填时请用「通用」。

12设置与快捷键

  • 录制快捷键：点输入框后直接按组合键；Esc 取消，Delete 清除。也可以手写，如 alt+cmd+d。
  • 规则：字母、数字、标点要搭配 ⌘、⌥ 或 ⌃；F1–F12 也要搭配修饰键；F13–F20 可以单独使用。快捷键按键盘的物理位置记录，切换输入法不影响。
  • 冲突：两个动作不能用同一组合；被其他应用占用时会在设置页提示，换一个即可。保存后菜单栏会显示新的快捷键。
  • 剪贴板使用的词典与空闲多久后新建会话也在这里调整；切换词典从下一段脱敏开始生效。
  • 登录时启动：开机后自动在菜单栏运行。

13记录

「记录」列出每次文件脱敏任务（时间、文件名、格式、各类别数量、任务号），以及每次调用的入口、应用、耗时、字符数和是否阻断。这里不保存正文和原值。删除任务会同时删除它的对照表，之后无法再回填。

15常见问题

打开时提示"无法验证开发者"

到「系统设置 → 隐私与安全性」点「仍要打开」，只需一次。

按快捷键没反应

确认菜单栏有 Tuomin 图标；到「设置」看快捷键是否启用、是否提示冲突。"选中文字"三项还需要辅助功能权限。

「选中脱敏并替换」提示没有读取到选中文字

先确认文字已选中；少数应用（如部分终端、受保护的输入框）不支持复制，改用普通剪贴板动作。

Finder 右键里找不到「用 Tuomin 脱敏」

先从「应用程序」打开一次 Tuomin，再到「系统设置 → 键盘 → 键盘快捷键 → 服务」里勾选它。新系统里它在「快速操作」子菜单中。

AI 工具里看不到 Tuomin 的工具

在「工具接入」点「自检」；四步都通过后重启客户端。卡片显示"指向旧位置"时，说明 Tuomin 被移动过，点「重新写入」。不要从 DMG 或「下载」文件夹运行 Tuomin。

回填时报"未知占位符"

通常是选错了任务或会话。剪贴板回填只能还原当前会话产生的占位符；AI 工具的回答请在「回答回填」选择对应的智能体会话。剪贴板与智能体会话的对照表 24 小时后清理，超时后无法再还原。

文件脱敏被拦下

错误提示会写明原因和建议：含宏的另存为普通 .docx / .xlsx / .pptx；有打开密码的先去掉密码；公式或工作表名里有敏感值的改成普通文字。拿不准时先用「解析并脱敏」得到文本版。

.doc / .xls 提示没有转换程序

安装 LibreOffice，或用 Word / Excel 另存为 .docx / .xlsx 后再处理。

出站闸门显示"禁止外发"

内容里有档位规定不能外发的类别（例如身份证号、密钥）。检查原文，必要时手动删去后重试。

退出时弹出"其他工具最近仍在使用 Tuomin"

最近几秒有 AI 工具或其他程序通过 Tuomin 处理过内容，退出会让它们连不上。确认没有正在进行的工作后点「退出 Tuomin」，否则点「继续运行」。正在处理文件时退出会中断这次处理，不会生成结果。

WorkBuddy 显示写入成功但模型列表里没有

在 Tuomin 向导里点「校验」；确认选的是配置了上游模型的项目应用。旧版本写入的条目格式不兼容时，重新点「生成并写入」会自动修正。

16卸载

  1. 点菜单栏 Tuomin 图标 →「退出 Tuomin」（或在 Dock 图标上右键退出）。
  2. 在「工具接入」里把已接入的 AI 客户端逐个「移除」（可选，但推荐）。
  3. 把「应用程序」里的 Tuomin 移到废纸篓。
  4. 如需同时清除数据（对照表、词典、记录），删除 ~/Library/Application Support/Tuomin 文件夹，并在"钥匙串访问"里删除名为 com.tuomin.workbench.mapping-store.v1 的项目。删除后已脱敏的文件将无法再回填。
