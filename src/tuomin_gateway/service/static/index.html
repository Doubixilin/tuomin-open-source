开始

敏感信息在本机换成占位符，再交给 AI；拿回回答后在本机还原。所有映射只保存在这台电脑上。

最快的用法：托盘／菜单栏 + 剪贴板

  1. 在任何应用里复制一段文字，按 ⌥⌘D 或点菜单栏「脱敏剪贴板」。
  2. 粘贴到任意 AI 对话框提问。
  3. 复制 AI 的回答，按 ⌥⌘R 或点「回填剪贴板」，再粘到文档里。

同一会话里多次复制使用同一套占位符。想让本单位的名称也被识别，去「本地词典」批量导入；想在 Claude Code、Codex 等工具里直接脱敏，去「工具接入」一键配置。Windows 可从托盘选择文件脱敏；Mac 可把文件拖到 Dock 或菜单栏图标上。

只在本机 127.0.0.1 运行词典与映射不出本机原值只在你解锁时显示不承诺零泄漏，请核对后使用

添加词条

类型用大写英文，例如 ORG（单位）、PERSON（人名）、PROJECT（项目）、SUPPLIER（供应商）。同一实体的简称填在别名里，脱敏时会按你当时写的写法还原。

批量导入

每行一个：名称,类型,别名|别名,风险，后三项可省略。类型可写 ORG / PERSON / PROJECT，或 单位、人名、项目、供应商、客户、地址。也可以选 CSV、Excel（.xlsx，第一张表，表头含「名称」「类型」「别名」「风险」）或之前导出的 JSON。先预览，确认后才写入。

从脱敏结果学习

把某次文件脱敏、智能体会话里识别出的单位、人名、地址等列出来（已在词典里的不再列），勾选后加入当前词典，下次就能稳定识别。

任何支持 STDIO MCP 的客户端都可以用这条命令。命令从本机数据目录读取凭证；Tuomin 没在运行时会自动在后台启动。

WorkBuddy 接入

演示模式只展示接入配置，不写入 WorkBuddy 或执行外部校验。

把本机网关接成 WorkBuddy 的自定义模型：自动定位端口，生成三条条目，写入 ~/.workbuddy/models.json（自动备份、旧端口自愈）。上游 API key 只写进 WorkBuddy 本地配置，不进 Tuomin、不进日志。

还没有项目应用？一键创建

按 WorkBuddy 需要的档位创建（strict、不严格回填、允许透明回填），并钉住上游模型。

在 WorkBuddy 里怎么用

  1. 写入后到 WorkBuddy 的模型列表中确认；若未出现，重新打开会话或重启 WorkBuddy。
  2. 在模型下拉里选「<应用>·脱敏·无感回填」日常使用；要看脱敏证据选「思维链mask」；自检用「全mask」。
  3. 只有走该自定义模型的会话经过 Tuomin，WorkBuddy 内置模型不经过网关。

设置

剪贴板、快捷键、登录自启，以及服务运行信息。

剪贴板与快捷键

点输入框后直接按组合键（Esc 取消，Delete 清除），也可以手写 alt+cmd+d。字母和数字需要搭配 ⌘、⌥ 或 ⌃；F13–F20 可单独使用。留空即不绑定，菜单栏里的动作始终可用。

「选中文字」三项不用先复制：选中文字按快捷键即可。「脱敏选中文字」把结果放进剪贴板；两个「替换」会直接替换选中内容，并恢复你原来的剪贴板。

管理 Token（外部浏览器）

在原生窗口里会自动注入，不需要填写。用浏览器打开时，从本机数据目录的 admin-token 文件复制。不要把 Token 放进 URL、聊天或截图。
