WorkBuddy 接入向导

把本机 Tuomin 网关接成 WorkBuddy 的自定义模型：自动定位网关端口 → 生成三条条目 → 写入 ~/.workbuddy/models.json（自动备份、旧端口自愈、实测热加载生效）。上游 API key 由你提供，只写入 WorkBuddy 本地配置，不落 Tuomin、不进日志。

还没有项目 app？一键创建

按 WorkBuddy 需要的档位创建：strict + refill_strict:false + allow_auto_refill:true，并钉住上游模型（客户端无法偷换模型）。

在 WorkBuddy 里怎么用

  1. 写入成功后 WorkBuddy 会自动重载 models.json（本机实测热加载，通常无需重启）。
  2. 打开任意会话，在模型下拉里选 「<app>·脱敏·无感回填」（日常使用）；要看脱敏证据选「思维链mask」；自检用「全mask」。
  3. 只有走该自定义模型的会话经过 Tuomin；WorkBuddy 内置模型不走网关。
